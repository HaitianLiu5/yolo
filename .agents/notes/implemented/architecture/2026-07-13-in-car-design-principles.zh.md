# Agent Note: 车载界面的设计原则

Status: implemented

[English](2026-07-13-in-car-design-principles.md) | 中文

## 问题

播放器首先由车内乘员在大尺寸车载触摸屏上使用（它的车机 profile），也在电脑或手机的浏览器里使用（它的 web profile），用户本人的网页与它并列。主要任务是尽量少打字、少精确点按，就能开始和控制媒体；控件在手机尺寸的浏览器里也要能用。没有明确的方向，每个界面都会慢慢变成开发者仪表盘，或者千篇一律的流媒体应用仿品。

## 决策

每个界面都遵循同一份设计背景：

- **气质：**沉静、直接、有电影感。它应该让人觉得可靠、专为汽车打造，而不像开发者仪表盘或千篇一律的流媒体仿品。
- **审美方向：**克制的黑色界面，对比度高，触控目标大，文字疏朗。功能状态比装饰更重要。避免霓虹效果、拥挤的卡片、细小的控件和大量模态的设置。
- **原则：**
  - 优先一次点按的选择，而不是需要输入的配置。
  - 在用户操作之前，先让当前状态可见。
  - 车内主要控件的触控目标至少 48 px（`--touch`）。
  - 播放控件在需要之前保持低调。
  - 在特斯拉和手机视口之间保持布局稳定。

调色板、间距、字号、圆角和触控尺寸都是 [`clients/player/src/style.css`](../../../../clients/player/src/style.css) 里由所有界面共用的 CSS 自定义属性：纯黑底上的中性 `oklch` 调色板、以 4 px 为单位直到 48 px 的间距、13 到 40 px 的字号，以及磨砂质感的菜单。滚动的列表不显示滚动条，后面还有内容的边缘改为渐隐并略带模糊，首页的横排和设置面板的纵向列表都是如此（由 [`scroll-edges.js`](../../../../clients/player/src/scroll-edges.js) 标记边缘）。所有控件使用 48 px 的触控目标（`--touch`）和 22 px 的图标，在车机默认显示大小下约为 60 个物理像素。正在观看的人看到的错误只有一句话和 **Try again**、**Back** 两个按钮，从不显示技术细节（[设备埋点](../feature/2026-10-11-device-telemetry.zh.md)）。

车机浏览器的窗口在车机应用栏的上方结束：窗口高 601 个 CSS 像素（920 个物理像素），特斯拉的状态栏、浏览器的工具栏和应用栏占去 1200 像素高屏幕的其余部分。所以布局不为应用栏留出空带，只保留底边自己的安全区（`--safe-bottom`，即手机的 Home 指示条）。播放器把画面放在整个窗口的正中，而不是顶栏下方区域的正中，因为顶栏会随控件一起隐藏，那样观看时画面会偏下。进度条和控件贴着窗口的底边，正好落在 16:9 画面下方的空带里，顶栏则在画面上方的空带里；菜单放在两者之间。

播放器的控件照着手机和平板上的 YouTube 应用来做，因为车机的屏幕是触摸屏（[`controls.js`](../../../../clients/player/src/controls.js)）。点一下画面，柔和的暗色蒙层上出现一层控件，蒙层整片均匀，上下边缘没有更暗的阴影带；再点一下、播放中过 3 秒，或者鼠标移出播放器，它就隐藏；暂停时它一直显示。点按本身从不暂停；在车机的屏幕上，不论浏览器报告的是哪种指针，每次按下都按触摸处理。这层控件包括顶栏（返回和标题）、画面正中的上一个、播放/暂停和下一个（Yolo 的历史里有更早的条目时才有上一个，队列里有条目时才有下一个），以及底边的 YouTube 桌面版控件栏：进度条横贯其上，下面一行把其余所有控件放在左边，左舵车的司机够得着：一个胶囊里是播放/暂停、音量和时间，另一个里是弹幕、字幕（CC）、音轨、设置和全屏按钮，音轨只在有音轨可选时出现。使用鼠标时，悬停会在按钮上方显示它的名字。没有画中画按钮。双击左侧或右侧三分之一处后退或前进 10 秒，之后每多点一下再加 10 秒，带 YouTube 那样的波纹，且不显示控件；按住画面时以两倍速播放，只限 `<video>` 引擎，因为 canvas 引擎的画面跟随它的音频时钟；向下滑动等于返回。弹幕留在控件下方，暂停时停在原处，由控件的蒙层压暗；字幕取 YouTube 的大小和位置：画面每 360 像素高对应 16 像素字号（至少 16），离画面底边为画面高度的 2%；底行显示时，字幕紧贴在它上方。鼠标指针随控件一起隐藏；流还在加载时，移动鼠标只显示指针。手机竖握时，和 YouTube 应用一样，顶栏和底行直接叠在画面上，只由正中一行播放和暂停；控件显示时，字幕移到画面下方的空带里。这一行放不下所有控件时（宽度不超过 640 个 CSS 像素），第二个胶囊可以横向滑动，边缘渐隐，每个按钮仍是完整的触控尺寸，不会被裁掉。使用鼠标时，点击播放或暂停，空格或 K、J 和 L、方向键、F 和 M 的作用与 YouTube 相同。

同一套 token 也用于电脑或手机浏览器里的 [Yolo Web](../feature/2026-10-11-yolo-web-client.zh.md) 和用户本人的网页，后者另加一套跟随系统设置的浅色方案（[用户本人的网页](2026-10-12-owner-web-pages.zh.md)）；Yolo 标志和各设备类型的图标来自同一个模块。列表、面板和网页用间距、分组和字号层级来组织结构，而不是边框和分隔线；保持同一条左边缘、操作放在右侧，只说必要的那一句。设置是一个面板，其中的破坏性操作在原地确认，绝不在对话框上再叠对话框；每个可按的控件按下时都有动作反馈，面板用键盘和触屏都能操作。

## 后果

各个界面通过这些 token 共用一套视觉语言，所以新界面会继承调色板、间距和触控尺寸，而不是另起炉灶。选择原生以外的[显示大小](../feature/2026-10-11-display-size.zh.md)会缩放每个 CSS 像素，所以触控目标也随所选大小变小。
