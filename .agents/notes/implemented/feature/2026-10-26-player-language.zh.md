# Agent Note: 播放器说这块屏幕的语言

Status: implemented

[English](2026-10-26-player-language.md) | 中文

## 问题

播放器原来只有英文。它的主人说中文，而最要紧的屏幕是车和手机，它们的浏览器可能设成英文：这台 Mac 的 Chrome 报的是 `en-US`，它发出的中文语音请求没有中文提示，语音模型只好自己识别语言，结果有些写成了繁体字。只跟着浏览器，说不清屏幕前的人读什么、说什么。

## 决策

播放器显示英文或简体中文，由每块屏幕自己选（[`clients/player/src/i18n.js`](../../../../clients/player/src/i18n.js)）。

- **选择。** **设置 › 这块屏幕 › 语言**提供自动、English 和简体中文，每种都用它自己的语言写名字，选择存在 `localStorage`（`yolo.language`）里，和这块屏幕问哪个 agent 一样。自动按顺序跟随浏览器的语言：第一个是中文（无论哪种文字、哪个地区）就是简体中文，第一个是英文就是英文，两者都没有就是英文。屏幕上做的选择优先于浏览器。改了之后页面会重新加载，所有内容都用新语言重画；语言只在页面加载时读一次。
- **文字。** 英文原文本身就是键：`t(text, values)` 返回这块屏幕语言里的文字，中文取自 [`clients/player/src/locales/zh-Hans.js`](../../../../clients/player/src/locales/zh-Hans.js)，目录里没有的就显示英文本身。值按名字放进去（`{agent}`），这样译文可以把它放在句子里任何位置。`index.html` 自己的文字，即它的文本节点和 `aria-label`、`placeholder`、`title`、`alt` 的值，在页面启动、任何东西画出来之前用同样的方法查找，`<html lang>` 标明语言。日期用这个语言作区域设置。
- **翻译什么。** 播放器自己显示的一切：主页、搜索、剧集、播放器的控件和菜单、加载和出错画面、提问和它的语音输入、配对，以及设置。设备事件、日志、错误码和屏幕发给 Yolo 的内容保持原样。Yolo 服务器写的文字，例如接口错误的消息，按服务器写的显示；标题、agent 的名字和 agent 的回答也一样。
- **对 Yolo 说什么。** 做了选择的屏幕，在语音请求（`POST /v1/agent/transcriptions?language=`）和问 agent 时带上这个语言；没做选择的照旧带浏览器的语言。所以设成中文的屏幕，不管浏览器怎么说，转录器都按中文听，写成简体字（[语音输入](2026-10-18-agent-from-the-screen.zh.md#voice-input)），它的 agent 也会被告知这块屏幕设成了 `zh-Hans`。
- **检查。** [`clients/player/test/unit/i18n.test.js`](../../../../clients/player/test/unit/i18n.test.js) 读取 `clients/player/src` 下每个对字面量调用的 `t()` 和页面自己的文字；有一句没有中文、目录里有一条没有任何地方显示，或者某个值在两种语言里名字不同，它就失败。所以文字在写下的地方以字面量经过 `t()`，从不经过变量。

Apple TV 应用不在其中，它用自己的文字。

## 曾考虑的替代方案

**只跟随浏览器的语言。** 不需要设置，但车和主人自己的浏览器都设成了英文，而主人读的、说的是中文，语音请求就是这样变成繁体字的。浏览器仍然是默认值；屏幕上的选择覆盖它。

**整个账号一种语言。** 主人的设置要在 passkey 会话之后，而车上很少有这个会话；两个人在不同屏幕上看，读的语言也可能不同。按屏幕选，在看得到的地方就能选，不用登录，和这块屏幕问哪个 agent 一样。

**符号键（`ask.listening`）或 i18next 之类的库。** 符号键需要在代码旁边再放一份英文目录，读任何一块屏幕的文字都要去查；库会给一个原本没有依赖的客户端加上依赖和格式。英文原文作键，代码读起来和原来一样，自己就退回英文，检查保证目录完整。

**不重新加载、就地切换语言。** 每块画面都得在切换时自己重画，模块加载时做好的文字会停在旧语言。语言很少改，而且是在设置里改，重新加载更简单、更完整。

**在节点上把转录器的繁体字转成简体。** 它只修好语音输入的字形，而且对所有主人都一样，包括读繁体字的人，也管不了播放器显示的语言。屏幕的选择把两件事一起解决，自动模式的屏幕仍然跟随它的浏览器。

## 后果

设成中文的屏幕通篇显示中文，不管浏览器怎么说，都按中文听、写成简体字。播放器里每句新文字都要在同一个改动里配上中文，这由检查保证；句子要整句写、用命名的值，而不是拼起来。Yolo 服务器和 agent 的文字不翻译，所以中文屏幕仍可能显示服务器的英文错误。现在只有英文和简体中文；再加一种语言，就是一个目录加上 `LANGUAGES` 里的一行。改语言会重新加载页面，屏幕正在播的内容会停下，直到续播。
