# Agent Note：在 iPhone 和 iPad 上下载、离线观看

Status: implemented

[English](2026-11-11-offline-downloads.md) | 中文

## 问题

主人出行时没有网络，比如在飞机上或在国外，希望 iPhone 和 iPad 应用能把视频存在设备上，在设备上播放。Yolo 原来做不到：每条流都是节点为一块边收边播的屏幕准备的。离线副本不能依赖是哪个来源在播这个条目，因为新的来源，比如由插件提供的剪辑项目成片，也应当能以同样的方式离线保存。

## 决定

iPhone 和 iPad 应用把一个条目的整条流按 Yolo 提供的样子保存在设备上，再用系统播放器从本地播放。它不需要改服务器，所以在任何带分享链接的版本上都能用。

### 流从哪里来

副本像朋友的浏览器那样要流（[分享链接](2026-10-20-share-links.zh.md)）：先 `POST /v1/shares` 为条目建分享链接，再带上设备真实的能力和视口 `POST /v1/share/<token>/stream`（[`Offline.swift`](../../../../clients/apple/YoloKit/Sources/YoloKit/Offline.swift) 里的 `APIClient.offlineStream`）。这条流不经过 Hub，所以做副本不会改变任何屏幕的会话、历史、进度或轨道偏好，节点也把它和主人自己的会话分开。探测发现远程直连在这里能用时，流为远程直连准备，否则走中继。分享链接只留在这台设备上，用于副本以后续传时再要流；它和其他分享链接一样七天后过期，主人可以在设置里撤销。

因为副本保存的是 Yolo 提供的东西，它不认识任何来源：来源插件的 `prepare()` 返回什么，转码与否，就保存什么。发送的能力是设备自己的，所以来源会选这台设备能解码的版本。

### 流怎样保存

`OfflineCopier` 把每个条目写进各自的文件夹：

- **MP4** 按 8 MiB 的范围取回，追加到一个未完成文件，再从文件播放。
- **HLS** 逐个文件镜像。主播放列表只留一个变体，即带宽最高的那个，加上它的默认音频；I 帧和字幕变体去掉。每个分段、初始化段和 AES-128 密钥四个一起取回，按去掉媒体令牌的路径命名，这样同一条目的新流给文件起同样的名字，做到一半的副本能从已有的文件继续。仍在增长的播放列表（正在转码）每两秒重读一次，直到结束；滑动的直播窗口，或三分钟不再增长的，被拒绝。FairPlay 密钥被拒绝。
- 流以 WebVTT 提供的**文本字幕**保存在视频旁边，仍在生成的轨道除外。默认显示 Yolo 选的那条，否则显示一条中文字幕。

AVPlayer 只通过 HTTP 播放 HLS，所以 `LocalMediaServer`（[`LocalMediaServer.swift`](../../../../clients/apple/YoloKit/Sources/YoloKit/LocalMediaServer.swift)）在 127.0.0.1 的空闲端口上提供这些文件夹，支持字节范围，拒绝文件夹以外的任何路径。

### 应用

[`Downloads.swift`](../../../../clients/apple/iOS/Downloads.swift) 把列表保存在 Application Support/Offline，不进备份，在应用打开时一次复制一个条目：屏幕保持常亮，离开应用时应用会要一点时间完成手上的文件。因没网而停下的副本在应用回来时继续；被 Yolo 拒绝的会说明原因。条目页的播放按钮旁有下载按钮，可选这台设备能播的最佳画质或较小文件（2 Mbps）；“下载”页列出副本，用系统播放器从上次停下的地方播放，并把保存的字幕画在画面上；长按可以选择或关闭字幕、删除副本。因为已配对的应用没有网络也能打开，这一页离线可用。

## 考虑过的方案

**`AVAssetDownloadURLSession`。** 它能在后台下载 HLS 并原生播放结果，但它不在模拟器里运行，会把仍在增长的播放列表当成直播，也没法保存 Yolo 单独提供的 WebVTT 轨道，所以既无法在 Mac 上验证，也不能用于转码。

**服务器上的下载路由。** 为副本提供流的 `/v1` 路由，或由节点把文件打包供下载，会比分享链接干净，但要先升级控制面和节点，副本才能用。

**像屏幕播放那样经 Hub 下载。** 它会接管这块屏幕的会话，并为没人看的视频写历史和进度。

**后台下载。** 后台 `URLSession` 能在应用关闭后继续，但系统会推迟、合并大量小的分段请求，而转码的播放列表必须在增长时读取。

## 后果

主人可以把 Yolo 能播的任何视频，来自任何来源，连同字幕保存在 iPhone 或 iPad 上。每个副本会在主人的列表里留下一条分享链接，复制时占用节点给朋友的两个流位之一。副本只在应用打开时制作，所以长的副本最好让手机插着充电。副本不和 Mac 或其他设备共享，离线观看的进度只留在设备上，Yolo 的历史不知道。来源用 FairPlay 保护的流和直播流不能保存。
