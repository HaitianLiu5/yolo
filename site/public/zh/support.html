技术支持

需要什么帮助？

适用于所有 Yolo app：车里或任何浏览器里的播放器、Apple TV 上的 Yolo TV，以及之后的 app。

部署 Yolo 用你的 Cloudflare 账号和家里的一台机器。 配对屏幕 车机、浏览器或 Apple TV，每块只需一次。 联系我们 GitHub Issues 或邮件。

部署 Yolo

Yolo 是自托管的。它的 app 不带任何内容，从你自己运行的 Yolo 播放。你需要：

一个 Cloudflare 账号
Workers 免费版够一家人用。
家里的一台机器
macOS 或 Linux，一直开着，装有 Node.js 22.12 或更新版本、yt-dlp、ffmpeg 和 Deno。它运行媒体节点，读取你的媒体。
域名，可选
没有域名时，Yolo 运行在你账号免费的 workers.dev 地址上。

交给 agent 来做

在那台机器上克隆仓库，用 Claude Code 或 Codex 打开，让它部署 Yolo。它会按 yolo-deploy 技能来做，只在需要你亲自操作时停下：

  1. 用一个链接和一个代码，从任何设备登录 Cloudflare。
  2. 批准计划：它要建的资源，以及你的地址。
  3. 用 npm run owner-code 给出的 6 位代码，在 https://<你的地址>/login 创建通行密钥。
  4. 配对第一块屏幕，愿意的话再连上一个 agent。

以后升级，让它按 yolo-upgrade 来做。随时检查 Yolo 的状态，运行 npm run yolo -- doctor；有问题的地方都附有修复办法。

配对屏幕

每块屏幕只配对一次，用你的通行密钥批准。配对码 10 分钟内有效，只能用一次。

车机或任何浏览器

  1. 打开你的 Yolo 地址，页面会显示一个二维码。
  2. 用手机扫码，用通行密钥登录。
  3. 确认名字和类型，然后点允许。

Apple TV

  1. 在家打开 Yolo TV。如果系统询问，允许访问本地网络。
  2. 确认它找到的服务器，或输入你的地址。
  3. 扫二维码、登录，然后点允许。

手机或电脑上已经登录了？这台设备自己的页面，点一下就能批准。

常见问题

没有自己的服务器，Yolo TV 能用吗？

不能。和其他媒体服务器的 app 一样，Yolo TV 从你自己运行的服务器播放，本身不带任何内容。

Yolo TV 找不到我的服务器。

确认 Apple TV 和家里的机器在同一个网络，并且媒体节点在运行（npm run yolo -- doctor）。如果之前拒绝了本地网络权限，请在 Apple TV 的设置里允许，或者直接输入地址。不在家时，输入地址就行。

配对码过期了。

配对码 10 分钟内有效。屏幕会显示一个新的，扫新的就好。

播不出来，或者一直在缓冲。

媒体节点必须开着并且在线。在家里的机器上运行 npm run yolo -- doctor，按提示修复没通过的检查。在家时视频直接从节点来；在外面走节点的远程地址，不通再经你的 Cloudflare 账号中转。网速慢时，播放器会自动降低画质。

Ask 或它的麦克风在哪？

媒体节点上运行 agent 插件（比如 Claude Code 或 Codex）后，Ask 才会出现。节点还装了转写插件时，播放器里才有麦克风。在 Apple TV 上，用 Siri 遥控器听写。

设备丢了。

在 Yolo 的设置里移除它，或者让你的 agent 来做。它的凭据立即失效。

通行密钥丢了。

在家里的机器上运行 npm run owner-code，15 分钟内到 https://<你的地址>/login 登录。新的通行密钥会替换掉所有旧的。

怎么把视频分享给朋友？

在播放器里点分享，或者让你的 agent 来做。链接在任何浏览器里都能播这一个视频，有效期 7 天，你可以在设置（Settings）的 Share links 里撤销。

Yolo 会收集我的数据吗？

不会。一切都留在你的 Cloudflare 账号和你的机器上。请看隐私政策。
