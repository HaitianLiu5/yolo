技术支持

适用于所有 Yolo 客户端：浏览器里的播放器（特斯拉车机浏览器或任何浏览器）、Apple TV 上的 Yolo TV，以及之后的客户端。

获取帮助：在 GitHub Issues 报告问题或提问，或发邮件到 support@useyolo.app。请写明你用的客户端和版本、你预期会发生什么，并且不要附上令牌和凭据。

你需要什么

Yolo 是自托管的：app 从你自己运行的 Yolo 服务器播放，本身不带任何内容。在屏幕能播放之前，你需要：

  • 一个 Cloudflare 账号。Workers 免费版够一家人用。
  • 一台一直开着的家用机器（macOS 或 Linux），装有 Node.js 22.12 或更新版本、yt-dlp、ffmpeg 和 Deno。它运行媒体节点，读取你的媒体。
  • 域名可有可无：没有域名时，Yolo 运行在你账号免费的 workers.dev 地址上。

部署 Yolo

最简单的办法是让 AI 编程 agent 来做。在家里的机器上克隆仓库，用 Claude Code 或 Codex 打开它，让它部署 Yolo。它会按 yolo-deploy 技能一步步来，只在需要你亲自操作的地方停下：

  1. 用一个链接和一个代码，从任何设备登录 Cloudflare（npm run yolo -- auth）。
  2. 批准计划：它要建的 Cloudflare 资源，以及你的地址。
  3. 用 npm run owner-code 给出的 6 位代码，在 https://<你的地址>/login 创建你的通行密钥。
  4. 配对第一块屏幕（见下），愿意的话再通过 MCP 连上一个 agent，比如 Claude。

以后升级，让 agent 按 yolo-upgrade 技能操作。随时检查实例状态，运行 npm run yolo -- doctor；每一项没通过的检查都附有修复办法。

配对一块屏幕

每块屏幕只需配对一次，用你手机上的通行密钥批准。配对码 10 分钟内有效，只能用一次。

浏览器：车机、电脑或手机

  1. 在浏览器里打开你的 Yolo 地址。页面会显示一个二维码和一个短代码。
  2. 用手机扫二维码，用通行密钥登录，确认屏幕的名字和类型，然后点允许。
  3. 在已经登录的手机或电脑上，也可以一键批准这个页面自己的配对码。

Apple TV 上的 Yolo TV

  1. 在和家里机器同一个网络的 Apple TV 上打开 Yolo TV。如果系统询问，请允许访问本地网络：它靠这个找到你的服务器。
  2. 找到你的服务器后，按一下确认。如果一个都没找到，就输入你的 Yolo 地址。
  3. 用手机扫它显示的二维码，用通行密钥登录，然后点允许。

常见问题

没有自己的服务器，Yolo TV 能用吗？

不能。Yolo TV 是你自己 Yolo 服务器的播放器，就像其他媒体服务器 app 之于它们的服务器。它不带任何内容，只播放你的服务器提供的东西。

Yolo TV 找不到我的服务器。

确认 Apple TV 和家里的机器在同一个网络，并且媒体节点在运行（npm run yolo -- doctor）。如果你之前拒绝了本地网络权限，请在 Apple TV 的设置里重新允许，或者直接输入你的 Yolo 地址；不在家时，只能输入地址。

配对码过期了。

配对码 10 分钟内有效。屏幕会换一个新的，扫新的二维码即可。

播不出来，或者一直在缓冲。

家里机器上的媒体节点必须开着并且在线。在那台机器上运行 npm run yolo -- doctor，按提示修复没通过的检查。在家时视频经局域网直接从节点播放；在外面时走节点的远程地址，不通就退回到经你 Cloudflare 账号的中转，网速慢时播放器会自动降低画质。

Ask 按钮或它的麦克风在哪？

媒体节点上装好 agent 插件（比如 Claude Code 或 Codex）后，Ask 才会出现。浏览器播放器里的麦克风，要节点上还装了转写插件才会出现。在 Apple TV 上，用 Siri 遥控器听写。

设备丢了，或者想移除一块屏幕。

在 Yolo 的设置里移除它，或者让你的 agent 来做。它的凭据会立即失效，屏幕回到配对界面。

通行密钥丢了。

在家里的机器上运行 npm run owner-code，在 15 分钟内到 https://<你的地址>/login 登录。新代码会替换掉所有已有的通行密钥。

怎么把一个视频分享给朋友？

用播放器里的分享按钮，或者让你的 agent 来做。链接在任何浏览器里都能播这一个内容，有效期 7 天，你可以在设置（Settings）→ Share links 里撤销。

Yolo 会收集我的数据吗？

不会。所有数据都留在你自己的 Cloudflare 账号和家里的机器上。见隐私政策。
