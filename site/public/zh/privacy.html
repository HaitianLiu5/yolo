隐私政策

生效日期：2026 年 10 月 23 日

Yolo 是自托管的媒体服务。它知道的关于你的一切，都存在你自己运行的服务器上：你自己的 Cloudflare 账号，和你自己家里的机器。Yolo 的开发者不为你的实例运行任何服务器，收不到你的任何数据；所有 Yolo app 都没有统计、广告或追踪。

本政策适用于所有 Yolo 客户端：浏览器里的播放器（给特斯拉车机浏览器用的车机模式，和给电脑、手机用的网页模式）、Apple TV 上的 Yolo TV，以及以后的客户端，比如 iPhone app。本政策也适用于这个网站。

简单说：Yolo app 只和你填写地址的那台 Yolo 服务器通信（那是你自己部署的），以及你家里的媒体节点。app 不会把任何东西发给开发者或任何第三方。你的观看历史、进度、设备、向 agent 提的问题和分享链接，都存在你自己的 Cloudflare 账号里，由你掌控，随时可以删除。

"你"和"主人"指谁

每个 Yolo 实例只有一位主人：用开源代码把它部署到自己 Cloudflare 账号和家里机器上的那个人。实例存的所有数据都由主人掌控。Yolo 的开发者刘海天发布代码和 app，但不为任何人运营实例，也看不到你的实例里有什么。

数据存在哪

  • 控制面是主人自己 Cloudflare 账号里的一个 Cloudflare Worker。它的数据库（Cloudflare D1）和日志（Workers Logs）都属于这个账号。
  • 媒体节点运行在主人家里的机器上。它读取主人的媒体、准备视频流，并运行主人选择加载的插件。
  • 每块屏幕只在设备本身保存自己的登录凭据和少量显示偏好。

Cloudflare 按主人自己和 Cloudflare 的协议托管主人的控制面，是主人的托管服务商；见 Cloudflare 的隐私政策。

主人的服务器存什么

数据用途
观看历史和播放进度在任何一块屏幕上从上次停下的地方继续，并显示最近看过的内容。
播放队列、播放列表，以及字幕和音轨偏好按你排好的顺序、用你偏好的语言播放。
已配对的屏幕：你给它起的名字和类型，以及它凭据的哈希认出每块屏幕，并能立刻移除。
主人的通行密钥（只有公钥）让主人登录设置，并批准新屏幕。
通过 Ask 提的问题，以及 agent 的简短回答显示对话并接着聊。不保存 agent 的推理过程和工具结果；90 天没有动静的对话会被删除。
分享链接：每个链接的哈希、对应的内容，以及被播放的次数让主人查看并撤销自己建的链接。链接 7 天后失效。
浏览器播放器的播放诊断写进主人的 Workers Logs，而不是数据库，用来排查卡顿和错误。发送前会去掉密钥类信息，从不包含录音或你说的话。

每个客户端发送什么

浏览器播放器（车机模式和网页模式）

  • 发给主人的服务器：浏览、搜索和播放的请求；播放报告（位置、状态、错误）；配对时拿到的设备凭据；以及上面说的诊断信息，包括浏览器的 user agent、屏幕尺寸和媒体能力，用来选出合适的视频流。
  • 发给主人的媒体节点：视频和字幕数据的请求，在家走局域网地址，在外面能用时走节点的远程地址。
  • 它把凭据和显示偏好存在浏览器的本地存储里。

Yolo TV（Apple TV）

  • 发给主人的服务器和媒体节点：和浏览器播放器一样的浏览、播放和进度请求。Yolo TV 自己不发送任何诊断或统计数据。
  • 它把服务器地址和凭据存在 Apple TV 的钥匙串里。
  • 图片、字幕和视频只从主人自己的服务器和节点加载。

以后的客户端

新的客户端，比如 iPhone 或 iPad app，用同一套客户端协议和主人自己的服务器通信，并遵守本政策。如果某个新客户端要发送这里没写的东西，本政策会在那个客户端发布之前更新。

本地网络权限

Yolo TV 和以后的 Apple 客户端会请求使用本地网络，原因有两个：

  • 找到你的服务器。你的媒体节点会用 Bonjour（_yolo._tcp）在家庭网络上广播你的 Yolo 服务器，app 就能直接列出它，不用你手动输入地址。
  • 在家播放。屏幕和媒体节点在同一个网络时，视频直接从节点送到屏幕，不绕道互联网。

app 不会扫描或上报你网络上的其他任何设备。

Ask 和语音

Ask 让屏幕把一个请求（比如"播下一集"）交给主人装在家里机器上的 AI agent（比如 Claude Code 或 Codex）。

  • 打字或说出的问题先到主人的服务器，再交给主人机器上的那个 agent。agent 用的是主人自己在它服务商那里的账号，所以 agent 处理的内容适用该服务商的条款和隐私政策。Yolo 的开发者收不到任何东西。
  • 浏览器播放器里的语音。主人的节点装了转写插件时，播放器可以在浏览器征得你同意后用麦克风录下你的请求。录音（最长 30 秒）经过主人的服务器交给主人节点上的这个插件，只有转写出的文字会传回来。录音从不写入磁盘、不记日志、不保存。转写插件由主人自己选择和配置，可能在主人自己的机器上运行，也可能调用主人设置的语音服务。
  • Apple TV 上的语音。Yolo TV 自己不录音。用 Siri 遥控器听写走的是 Apple 的系统听写，由 Apple 按它自己的隐私政策处理，Yolo 只收到听写出的文字。

分享链接

主人可以生成一个链接，让朋友不用配对、在浏览器里看某一个内容，有效期 7 天。朋友的页面只能播这一个内容；朋友的操作不会写进主人的历史或进度，也不会识别朋友的身份。主人的服务器会统计每个链接被播放了几次。

主人选择的插件和 agent

媒体节点加载主人配置的插件：媒体来源、AI 字幕、转写和 agent。插件可能会联系它对应的服务（比如来源插件会从视频所在的网站取视频）。主人也可以通过 MCP 把 AI 助手连到自己的服务器。这些连接都是主人自己的服务器用主人自己的账号建立的，不是 Yolo app 建立的，也不是 Yolo 的开发者建立的。

Yolo 的开发者收集什么

什么都不收集。Yolo app 里没有统计、崩溃上报或广告软件，不会跨 app 或网站追踪你，也不向开发者发送任何东西。如果你在设备设置里允许，Apple 可能会把崩溃报告和使用统计分享给开发者，这部分适用 Apple 的隐私政策。这个网站是静态的，不设 Cookie，也没有统计。

如果你给支持邮箱发邮件或在 GitHub 上开 issue，开发者会看到你发来的内容。请不要附上媒体令牌、设备凭据或你不想分享的个人信息。

你对数据的控制

  • 在 Yolo 的设置里移除一块屏幕，它的凭据立即失效，屏幕回到配对界面。
  • 在设置（Settings）→ Share links 里撤销任意分享链接。
  • 删除你自己 Cloudflare 账号里的 D1 数据库和 Worker，以及家里机器上的数据，就能删掉对话、历史和其他所有数据。
  • 从设备上删除 Yolo app 会删掉它在那台设备上存的东西；在 Apple TV 上，也请在 Yolo 的设置里移除这块屏幕，因为钥匙串可能还留着它的凭据。

儿童

Yolo 不面向儿童。屏幕上播放的是主人自己的媒体和选择。
