隐私政策 / 2026.10.31

你的数据，留在你家。

Yolo 是自托管的。它知道的一切，都在你自己的 Cloudflare 账号和你自己的机器上。我们看不到。

适用于播放器、Yolo TV 和所有 Yolo app阅读政策
0B任何 Yolo app 发给开发者的数据
0追踪、统计或广告
1所有数据的主人：你
01归谁所有

是你的，不是我们的

每个 Yolo 只有一位主人：用开源代码把它部署到自己 Cloudflare 账号和家里机器上的那个人。它存的一切都由主人掌控。Yolo 的开发者刘海天发布代码和 app，不为任何人运行 Yolo，也看不到你的 Yolo 里有什么。

本政策适用于所有 Yolo app：浏览器里的播放器（给特斯拉用的车机模式，和给电脑、手机用的网页模式）、Apple TV 上的 Yolo TV，以及以后的 app，比如 iPhone 版。本政策也适用于这个网站。

02数据在哪

三个地方，都是你的

你的服务器
你自己 Cloudflare 账号里的一个 Cloudflare Worker。它的数据库（D1）和日志（Workers Logs）都属于这个账号。Cloudflare 按你和它的协议、按它的隐私政策为你托管。
你的媒体节点
运行在你家里的机器上。它读取你的媒体、准备视频流，并运行你选择的插件。
每块屏幕
只在设备本身保存自己的登录凭据和少量显示偏好。
03保存什么

服务器存什么，为什么

历史和进度
让你在任何一块屏幕上从上次停下的地方继续。
队列、播放列表、音轨
让你排好的内容接着播，用你偏好的语言。
已配对的屏幕
你给每块屏幕起的名字和类型，以及它凭据的哈希，用来认出它、随时移除它。
你的通行密钥
只有公钥，用来让你登录设置、批准新屏幕。
你说的语言
你在设置里选了的话保存下来，让每块屏幕都按这些语言听你说话。
Ask 对话
你的提问和 agent 的简短回答，用来显示并接着聊。不保存它的推理过程和工具结果。90 天没有动静的对话会被删除。
agent 放到屏幕上的东西
你的 agent 放到屏幕上的便签、图片和选项，保留到被关掉或过期（选项 10 分钟后过期）；以及你选了什么、关了什么，保留 24 小时，让 agent 能据此行事。
更正过的匹配
你或你的 agent 说明某个内容是哪部电影或哪一集、或者哪个都不是时，记下这个选择，让它一直这样显示。
分享链接
每个链接的哈希、对应的内容和被播放的次数，让你查看和撤销。链接 7 天后失效。
播放诊断
只来自浏览器播放器，写进你的 Workers Logs，用来排查卡顿和错误。发送前去掉密钥类信息。从不包含你的声音，也不包含你说的话。
04发送什么

每个 app 发送什么

播放器，在车里或任何浏览器

发给你的服务器
浏览、搜索和播放的请求；播放报告（位置、状态、错误）；配对时拿到的凭据；以及上面说的诊断信息，包括浏览器的 user agent、屏幕尺寸和媒体能力，用来选出合适的视频流。
发给你的媒体节点
视频和字幕的请求，走家里的网络，或走节点的远程地址。
存在设备上
它的凭据和显示偏好，在浏览器的本地存储里。

Yolo TV

发给你的服务器和节点
同样的浏览、播放和进度请求。自己不发送任何诊断或统计。每张图片、每条字幕、每段视频都来自你自己的服务器和节点。
存在设备上
你服务器的地址和它的凭据，在 Apple TV 的钥匙串里。

以后的 app

新的 app 用同一套协议和你自己的服务器通信，并遵守本政策。如果某个 app 要发送这里没写的东西，本政策会在它发布之前更新。

05本地网络

本地网络，只为两件事

找到你的服务器
你的媒体节点用 Bonjour（_yolo._tcp）在家庭网络上广播你的 Yolo 服务器，Yolo TV 和 Yolo 的其他 Apple app 就能直接列出它，不用你输入地址。
在家播放
屏幕和节点在同一个网络时，视频直接从节点送到屏幕，不出互联网。

不扫描、也不上报你网络上的其他设备。

06Ask 与语音

听得见你，但不留下你的声音

Ask 把一个请求（比如“播下一集”）交给你装在家里机器上的 AI agent，比如 Claude Code 或 Codex。你的问题先到你的服务器，再交给那个 agent。agent 用的是你自己在它服务商那里的账号，它处理的内容适用该服务商的条款和隐私政策。

在浏览器里
你的节点装了转写插件时，播放器可以在浏览器征得你同意后录下你的请求。录音最长 30 秒，经你的服务器交给你节点上的这个插件，只有文字传回来。录音从不写入磁盘、不记日志、不保存。插件是你自己选择和配置的，可能在你的机器上运行，也可能调用你设置的语音服务。
在 Apple TV 上
Yolo TV 从不录音。用 Siri 遥控器听写，走的是 Apple 自己的听写，适用 Apple 的隐私政策，Yolo 只收到文字。
07分享

一个视频，给一位朋友，七天

分享链接让朋友不用配对，在任何浏览器里看一个内容，有效期 7 天。朋友只能看到这一个内容。他们的操作不会碰你的历史或进度，也不会识别他们的身份。你的服务器会统计每个链接被播放了几次。

08你的选择

你选择的插件和 agent

你的媒体节点加载你配置的插件：媒体来源、AI 字幕、转写、agent、给其他插件用的模型，以及元数据。插件可能会联系它对应的服务，比如来源插件会从视频所在的网站取视频。你也可以通过 MCP 把 AI 助手连到你的服务器。这些连接都由你的服务器、用你的账号建立。Yolo app 不建立它们，Yolo 的开发者也从不参与。

认出一个视频
为了认出一个视频是哪部电影或哪一集，你的媒体节点把它的标题、简介、上传者、时长和文件名发给一个 AI 模型，从不发送视频本身或你的历史。它经过你家里机器上已登录的 Codex 或 Claude Code，或者你为 Yolo 登录的订阅，以你在那家服务商的账号发送，适用它的条款和隐私政策。把模型插件移出你的配置就能关掉这一项。
海报和演员
为了显示一部电影或一集的海报、简介和演员，你的媒体节点在 Wikidata、Wikipedia、TVmaze 和 Bangumi 里查找它，发送的是作品的名字（发给 Wikipedia 的是它找到的那篇文章）以及季和集号，从不发送视频本身或你的历史。你设置了自己在 The Movie Database 申请的 key 时，它也会在那里搜索；没有 key 时，什么也不会发到那里。把元数据插件移出你的配置就能关掉这一项。
登录视频网站
当你为 Yolo 登录一个你付费的视频网站，比如用微信扫码登录腾讯视频，你的媒体节点把这个登录保存在它自己的机器上，向那个网站续期，只用它从那个网站播放。它从不离开节点。npm run yolo -- accounts logout 会删除它。
09我们收集什么

什么都不收集

Yolo app 里没有统计、崩溃上报或广告代码，不会跨 app 或网站追踪你，也不向 Yolo 的开发者发送任何东西。如果你在设备设置里允许，Apple 可能会把崩溃报告分享给开发者，这部分适用 Apple 的隐私政策。这个网站是静态的，不设 Cookie，不从别人那里加载任何东西，也不统计访问。

你给支持邮箱写信，或在 GitHub 上开 issue 时，我们会看到你发来的内容。请不要附上媒体令牌、凭据，或你想保留的个人信息。

10你的掌控

由你掌控

  • 在 Yolo 的设置里移除一块屏幕：它的凭据立即失效，屏幕回到配对界面。
  • 在设置（Settings）的 Share links 里撤销任意分享链接。
  • 删除你 Cloudflare 账号里的 D1 数据库和 Worker，以及家里机器上 Yolo 的数据，就删掉了一切。
  • 删除 Yolo app 会删掉它在那台设备上存的东西。在 Apple TV 上，也请在 Yolo 的设置里移除这块屏幕，因为钥匙串可能还留着它的凭据。
11其他

儿童、变更与联系方式

Yolo 不面向儿童。播放的是主人自己的媒体，出于主人自己的选择。

变更会发布在这里，并更新生效日期。每一个历史版本都在公开仓库里。

写信到 support@useyolo.app，或在 GitHub 上开 issue。
